## 📋 Launcher Changelog v0.6.25

### ✨ New Features

#### Play Screen
- **3D Player Rig** - The play screen renders your skin on an animated rig with cosmetics, cape, nametag and promo outline
- **Idle Emotes** - Idle animations between play-screen loads, with a rare special wave and random downloaded emotes
- **Skin Animation Toggle** - Turn the rig's animation off in settings
- **Local-First Cosmetics** - Cosmetics resolve from the downloaded asset cache first, so they render instantly and offline

#### AFK Points & Ads
- **Rewarded Ad Window** - A launcher-styled ad window with live balance, 7-day streak track and reward pop
- **Shop Tab** - Buy from the AFK Points catalog inside the ad window
- **Ad-Gated Daily Claim** - Watch one ad, then claim the daily bonus
- **Consent Reset** - Advanced settings can reopen the ad window with consent wiped

#### Settings
- **Discord-Style Settings Dialog** - Settings is now a searchable modal with a category sidebar and scrollspy
- **Font Switcher** - Pick the pixel font, a preset, or any font installed on your machine
- **Sidebar Label Toggle** - Show or hide the captions under the sidebar nav icons
- **Custom Media Background** - Use your own image or video as background, with opacity, blur and visibility controls

#### Import & Export
- **.mrpack Export** - Export a profile as a Modrinth modpack that runs in other launchers
- **CurseForge Export** - Export a profile as a CurseForge modpack
- **Modpack Import Review** - Review a modpack before importing it, with drag-and-drop feedback

#### CLI
- **Install a Modpack by ID** - `modpack --id <project>` installs and launches a Modrinth or CurseForge pack

#### Backups
- **Profile Backup Restore** - Settings → Testing lists `profiles.json` backups and restores one live, without a restart [#324](https://norisk.gg/issues/324)

#### Logs
- **Log Privacy** - Usernames, tokens, emails and UUIDs are now redacted in the log file itself, not only in the viewer [#976](https://norisk.gg/issues/976)
- **Log Selection & Copy** - Drag-select log lines and copy them with Ctrl+C; the log window is fully localized

#### Content Cache
- **Clear Content Cache Button** - Debug → Testing can drop all cached Modrinth/CurseForge lookups and file hashes

### 🐛 Bug Fixes

#### Launch & Loaders
- **Offline Launch** - Minecraft launches from a warm cache without internet instead of hanging or never showing a window
- **Forge & NeoForge Launch** - The classpath is derived from the version JSON, fixing crashes and mods loading 1.12-era classes [#804](https://norisk.gg/issues/804)
- **Duplicate Libraries** - Libraries are keyed by Maven coordinate, so no jar is dropped or shipped twice [#804](https://norisk.gg/issues/804)
- **NeoForge Early Services** - Early-service jars are handed to the loader instead of the class path, so class-rewriting mods load [#823](https://norisk.gg/issues/823)
- **Loose Jars on Fabric** - A jar dropped into the instance's own `mods` folder is loaded again [#805](https://norisk.gg/issues/805)
- **Non-Latin Profile Names** - Profile folders are transliterated, so a pack named in another script starts [#830](https://norisk.gg/issues/830)
- **Default RAM** - New profiles get 2/4/6 GB based on your system memory instead of a flat 2 GB [#811](https://norisk.gg/issues/811)
- **Offline Toast** - The "multiplayer unavailable" toast only shows on a real launch-time connection failure

#### Mods & Modpacks
- **Missing Dependencies** - Dependencies resolve for the profile's loader on both platforms, including nested ones [#808](https://norisk.gg/issues/808)
- **Wrong Version Installed** - Installing a mod into a new profile uses the version you picked [#835](https://norisk.gg/issues/835)
- **Update All Duplicates** - Updating every mod no longer leaves the same library behind several times [#981](https://norisk.gg/issues/981)
- **Delisted Pack Files** - Modpack files the API no longer knows install from the manifest instead of silently vanishing [#818](https://norisk.gg/issues/818)
- **Pack Contents Misplaced** - Imported resource, shader and data packs land in their own folders, not in `mods/` [#795](https://norisk.gg/issues/795)
- **Dropped Shaderpacks** - A dropped `.zip` is routed by the open tab instead of always going to the modpack importer [#817](https://norisk.gg/issues/817)
- **URL Mods** - Mods sourced from a URL are downloaded instead of listed and skipped
- **Modpack Version Choice** - The CLI installs the newest pack version, not a years-old build marked stable [#824](https://norisk.gg/issues/824)
- **Mod Search** - The search is debounced and stale responses are discarded, so results match the search box
- **Update Check Outage** - A failed platform check is no longer cached as "no update" for 30 minutes
- **Bulk Lookups** - One unparseable project no longer discards the whole batch, which cost 97 of 98 mods their icons
- **CurseForge Loader Parsing** - Loader ids and versions parse correctly on import and export

#### Accounts
- **Invalid Session on First Join** - The Minecraft token's own expiry is tracked and in-game token handbacks are consumed [#278](https://norisk.gg/issues/278)
- **accounts.json Rewrites** - The account file is no longer rewritten dozens of times per render, and saves are atomic

#### Security
- **MOTD & Rich HTML** - Server MOTDs and mod descriptions go through DOMPurify instead of bypassable regex sanitizers
- **Ad Surface** - The ad iframe is sandboxed and its window dropped to a minimal capability
- **Export Symlinks** - Symlink paths are filtered and loops tracked, so an export cannot escape the profile or run out of memory

#### Interface
- **Flickering Mount Animations** - Entrance animations run before paint and honour the motion setting
- **Missing Icons** - 22 icon names that never existed are replaced, including the disk-usage icon
- **Profile Icon & Disk Size** - Both paint on the first render instead of fading in a frame later
- **Loading Spinner** - Loading states use a real spinner instead of a refresh arrow
- **Toggle Knob** - The switch knob always slides, even with background animations off
- **White Skin on Startup** - The play screen no longer shows an untextured skin until a remount
- **Avatar Flicker** - The account head no longer flickers on the preferred account
- **Disabled Content** - Disabled items are struck through instead of only dimmed
- **Log Autoscroll** - The log window reliably sticks to the newest line [#346](https://norisk.gg/issues/346)
- **Input Radius** - The radius slider no longer clips text inside transparent chrome inputs
- **Tooltips** - Action tooltips are static and stay inside the viewport
- **Disk Space on Linux/Flatpak** - A `statvfs` fallback fixes "no disk found" and "0 mb available"
- **Escaped Paths in Logs** - Paths logged with escaped separators are masked too [#976](https://norisk.gg/issues/976)
- **Mod Detail Overflow** - Description and sidebar text no longer overflow

### ⚡ Performance

#### Content & Mods
- **SQLite Content Cache** - The 25 MB JSON cache became a database, so a write is one row and startup parses nothing
- **Cache Warmed on Install** - Installing a pack fills the cache, so opening its tab no longer re-hashes and re-fetches everything
- **Cached Hashes & Metadata** - File hashes and platform metadata persist, so a content tab does not redo its scan on every open
- **Mod Names** - Names arrive with the list instead of popping in a round-trip later
- **Cached Taxonomy & Detail Pages** - Filters and mod detail pages are cached: 12 upstream fetches per session down to 0
- **Virtualized Content List** - Only the visible tiles render, so a 543-mod profile stays responsive
- **Faster Local Listing** - Per-item logging is gone: 520 ms → 144 ms on a 543-mod profile
- **Profiles List** - No version-list request per modpack card when opening the list
- **Mods Tab** - Renders from the profile store instead of 300-400 ms of blank screen per visit

#### Launch & UI
- **Install Progress** - Progress events are throttled, so the UI no longer freezes during asset download and extraction
- **Offline Icons** - Icons are bundled instead of fetched, removing the layout shift on every icon
- **System RAM** - Total memory is read once instead of enumerating every process, disk and sensor

### 🧹 Chores
- **Dead Code Removed** - The V1/V2 profile views, the old search UI, the pre-v2 wizard and unused components: ~23,000 lines across 71 files
- **Migration Registry** - One-time profile migrations are recorded, so they no longer overwrite your settings on every start
- **One Request Path** - All APIs go through a shared request builder and the shared HTTP client
- **Rust Tests in CI** - The test suite runs on every push, with a read-only token
- **Stable Migration Checksums** - Migrations are pinned to LF, so a Windows build no longer silently disables the cache
- **Signed Windows Builds** - Windows builds are signed with Azure Artifact Signing

## 📋 Launcher Changelog v0.6.26

### ✨ New Features

#### Clips
- **Clip Recording** - A replay buffer holds the last half minute of your game and a hotkey saves it as a clip. Windows only
- **Clip Library** - Clips get their own sidebar page with a still, length, name and favourite star per clip, plus renaming, deleting and a storage limit
- **Clip Cutter** - Trim a clip with one lane per audio track and a preview that follows the sliders
- **Vertical Export** - Cut a nine by sixteen column out of a clip and see what it keeps before spending a minute on encoding
- **Record One Other Program** - Pick another open program in the settings; capture follows whatever is in front and returns to Minecraft when it comes back
- **Clip Folder** - Choose where clips are written, with a reset to the default location
- **Hotkeys** - The numpad, the lock keys and the side mouse buttons can be bound, and the key keeps working inside the game
- **On-Demand Runtime** - The capture engine is fetched and verified on first enable instead of shipping in the installer: the Windows download drops from 52 MB to about 18 MB and saves roughly 126 MB for everyone who never turns clips on

#### Sync Packs
- **Share Folders, Files and Mods Between Profiles** - Named containers that profiles subscribe to. Folders become junctions pointing at a master, `options.txt` is merged key by key with comments kept, and pack mods resolve per game version and loader without ever touching the instance mods folder
- **Target Presets** - Each preset says what it actually syncs
- **Pack Management** - Pack icons, renaming, multi select and batch actions in a reworked entry list

#### Profiles
- **Import Instances From Other Launchers** - The profile wizard imports from Modrinth App, CurseForge App, Prism, MultiMC and ATLauncher. Jars resolve to managed Modrinth and CurseForge mods pinned to the instance loader and version, unresolved ones stay local, and config, worlds and resourcepacks are copied through an allowlist
- **One Pack Picker** - The content tab, the profile settings and the creation wizard now share one grouped and sorted NoRisk pack list that reads its order from the pack config

#### Accounts
- **Welcome Screen** - A launcher start without an account shows a welcome screen and sign-in prompts instead of an empty shell

#### Capes
- **Unequip A Cape** - The launcher can equip "no cape", and the vanilla no-cape button unequips a custom cape too, which is what people expected it to do

#### Crash Help
- **Localized Crash Texts** - The crash check sends the launcher's language and renders the curated entry in it
- **One-Click Pack Switch** - When the profile's NoRisk pack build is the cause, the offered fix switches the pack and can be reverted

### 🐛 Bug Fixes

#### Launch & Repair
- **Repair Fixes The Game Too** - Libraries and natives are verified before mods, so a broken installation is repairable instead of only the mods folder being refetched
- **Client Jar** - Repair verifies the client jar, not just the libraries
- **Legacy Java On Apple Silicon** - An arm64 JVM is rejected for legacy versions, which crashed before the window opened with a missing arm64 `liblwjgl.dylib`
- **Offline Launch** - The NoRiskClient asset manifest is written next to the assets it describes and read back when the backend cannot be reached, so a launch no longer dies on data that is already on disk
- **Re-Downloaded Log Config** - Mojang's log4j config is left untouched and verified against its manifest sha1 instead of its size. The launcher's plain-text rewrite lives beside it, so the file is no longer considered broken and refetched on every start

#### Profiles & Content
- **Duplicate Local Content** - Local content is deduplicated and every tile keyed uniquely [#775](https://norisk.gg/issues/775)
- **Duplicate Dependencies** - Dependency resolution is deduplicated across a whole batch
- **Imported Packs** - An imported instance applies the NoRisk pack you picked, and no longer inherits another profile's sync packs
- **Export & Import** - Sync pack ids are not carried through an export or import
- **Edited Worlds** - A world you changed while a sync pack was off is kept instead of being overwritten
- **Released Folders** - A folder is released from its profiles when its target goes away

#### Cosmetics & Skins
- **Cosmetic Settings** - Your per-cosmetic scale, offset and color from the outfit reach the launcher rig again, so cosmetics sit where they sit in game [#1030](https://norisk.gg/issues/1030)
- **No WebGL** - A device without WebGL falls back to a flat skin instead of showing nothing [#1102](https://norisk.gg/issues/1102)

#### Logs
- **Clearing, Scrolling And Capture** - Cleared lines stay gone, dragging the scrollbar counts as scrolling away from the tail, and a rotated process log keeps being forwarded [#1152](https://norisk.gg/issues/1152)

#### Interface
- **Discord Reconnects** - The launcher backs off while Discord is unreachable instead of retrying in a tight loop
- **Action Bar Blur** - The blur shows while the bar fades in, not after
- **Crash Report Contents** - The report says what the resolver actually delivered instead of the mod toggle

#### Platforms
- **macOS App Icon** - The build ships our actual logo, compiles the asset catalog in CI, adds the macOS 26 icon and fixes the dmg background and icon position
- **Signed Windows Builds** - The launcher executable and the capture engine are both code signed

### ⚡ Performance

- **Profiles In SQLite** - `profiles.json` was rewritten in full on every change: 22.8 MB and 425 profiles per mod toggle, 509 ms of the 543 ms a toggle took. Profiles live in `app.db` now, writes touch only the rows that changed, and the migration escrows the old file instead of deleting it
- **No Re-Hashing On Launch** - Minecraft libraries are no longer read and hashed on every launch when existence, size and ZIP integrity already answer the question: 52 ms down to 22 ms
- **Player Appearance Cache** - The play screen appearance is cached in memory and in `app.db`
- **Off The Hot Path** - File hashing and profile directory sizing moved to blocking threads, and the profile list payload no longer carries every mod

### 🧹 Chores
- **Configurable Log Level** - A log level setting plus `NRC_LOG_LEVEL`, with the startup narration condensed to a launch summary
- **Shared Logging Crate** - Logging and redaction moved into a shared crate that redacts secrets as it writes
- **Clips Beta Notice** - The clips page says it is beta and links where to send feedback, and the tab explains that clips are Windows only instead of hiding itself
- **Clip Telemetry** - Anonymous usage and performance data for the clip feature
- **Redistributed Licences** - The licences of the binaries we ship alongside the launcher are included

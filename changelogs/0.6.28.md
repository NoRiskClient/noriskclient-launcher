## 📋 Launcher Changelog v0.6.28

### ✨ New Features

#### Clips
- **Clips On macOS** - A native capture engine records clips on macOS, encoded on the GPU through VideoToolbox. Replay buffer, hotkey, cutter and vertical export work like they do on Windows
- **macOS Permissions** - The launcher asks for screen and microphone access, says which one is missing, opens the right System Settings pane and picks up once you grant it. The microphone is only requested if you actually record one

#### Crash Reporting
- **You Decide What Gets Sent** - The dialog says that the log goes to mclo.gs, and a checkbox controls whether the crash is also sent to the NoRisk team. With it off only the upload happens and the link is copied for you

### 🐛 Bug Fixes

#### Clips
- **AMD Encoders** - B-frames and pre-analysis were asked of hardware that cannot deliver them, which stalled the encoder. AMD cards record now
- **Older Adapters** - Capture opens on feature level 11.0 when the adapter cannot do 11.1
- **Minimised Game** - A minimised window kept failing the attach and put an error in the overlay every two seconds. The search now waits for a drawable window
- **Recovery** - The attachment is released after a recoverable error and a clip that found nothing re-attaches, as the overlay promises
- **Honest Errors** - An empty buffer, a stalled encoder, a frozen source and a driver that cannot mirror are reported instead of silently producing nothing or an upside-down recording
- **Hotkeys** - Hotkeys are preserved and a macOS attachment can be cancelled safely

#### Interface
- **Minecraft Logs Window** - Launching from the logs window works again. That window never loaded your accounts, so the account check aborted every launch and the sign-in prompt could not render, which is why the button looked dead. Its instance icon is crisp now too
- **Clips Tab** - The clip page is shown wherever clips are supported instead of on Windows only
- **Settings** - A tab with no sections no longer crashes the scroll spy

### 🧹 Chores
- **Our Own Dependency Mirror** - FFmpeg autobuilds are deleted after a couple of weeks, so the pinned download started returning 404 and broke the Windows build. Those files come from our own release now, still pinned by SHA256

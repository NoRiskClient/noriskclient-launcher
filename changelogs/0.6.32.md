## 📋 Launcher Changelog v0.6.32

### ✨ New Features

#### Sharing
- **Share Clips and Screenshots** - Upload a clip or screenshot to norisk.gg with a title and choose how long it stays online. The link is copied and opens in your browser right away
- **Right Click on Screenshots** - Screenshots now have a right click menu to view, share, copy, show in folder or delete them
- **Share Logs** - Logs and crash reports are shared to norisk.gg. If that is not reachable, they go to mclo.gs instead

#### Profiles
- **New Profile Settings** - Every settings tab got a cleaner look with less text, so the important options are easier to find
- **Easier Version Picker** - The newest Minecraft versions are shown as buttons, older ones and snapshots are one click away
- **Always the Latest Loader** - A custom loader version can now be set to "Always the latest", so the profile keeps getting new loader updates
- **Memory in GB** - Memory is shown in GB with quick buttons and a warning when you give Minecraft too much

#### Launcher
- **Updates in the Background** - New launcher versions download in the background and install when you close the launcher, so you never wait for an update when you open it. To update right away, click the update button next to the NoRisk Client title
- **Updates on Mobile Data** - On a phone hotspot or another metered connection, updates are no longer downloaded automatically
- **RPM Package** - The launcher is now also available as an RPM package for Fedora and other RPM based Linux systems
- **New News Feed** - News now come straight from NoRisk, show in your language and load more as you scroll. Hover a card to see that it opens
- **Game Detection** - Graphics drivers and overlays can now recognize the game as Minecraft

### 🔒 Security
- **Java4Shell Protection** - The launcher now starts Minecraft with Java settings that block the Java4Shell security issue, so a harmful server cannot use it against you. This works for every Minecraft version and mod loader, nothing to do on your side

### ⚡ Performance

#### Launcher
- **Faster Launcher Start** - The launcher opens and shows the Play button sooner, because your profiles load from disk first and startup work runs side by side
- **Faster Game Start** - Pressing Play on a profile that is already installed starts the game in a fraction of a second instead of several seconds, because files that were already checked are not checked again
- **Faster Clip Notification** - The "clip saved" notification appears sooner, because it no longer loads the whole launcher in the background
- **Less Disk Space Per Profile** - NoRisk Client files are no longer copied into every profile. All profiles use one shared copy, which saves space and time on every start

### 🐛 Bug Fixes

#### Modpacks
- **Modpacks With Extra Files** - Modpacks from Modrinth that ship extra files next to their mods, like Aero SMP, no longer crash while loading. Install the modpack again to get the fix
- **Modpack Changelogs** - Modpack versions without a changelog no longer show a made up one

#### Launcher
- **Stuck Login** - If the Minecraft login server stops answering, the launcher gives up after a few seconds instead of waiting forever
- **No Profile Selected** - Pressing Play without a selected profile shows an error again instead of doing nothing
- **Installation Tab Freeze on Linux** - The installation tab no longer freezes the launcher on Linux
- **Symlinks on Linux and macOS** - Opening a linked folder from the symlinks tab works on Linux and macOS again

### 🧹 Chores
- **Tauri 2.12** - The launcher now runs on a newer version of its app framework
- **Keep Local Assets** - The designer setting is gone, because it no longer had any effect
- **Cleanup** - Removed unused code, packages and settings that did nothing
